分辨率适配计算

本机为 Linux X11 4K；对端为 MacBook Air M4。32GB 只是内存配置，不影响屏幕。

设备原生 / 逻辑物理 / 缩放
本机 Linux 4K3840×2160 / 1920×1080631×360mm · 2.0× · 154 PPI
Air 13.6"2560×1664 / 1470×956293×183mm · 1.741× · 224 PPI
Air 15.3"2880×1864 / 1710×1107330×206mm · 1.684× · 224 PPI

速度倍率 = (Air 逻辑宽 / Air 物理宽) / (本机逻辑宽 / 本机物理宽)：
Air 13.6"：5.017 / 3.043 = 1.65×；Air 15.3"：5.182 / 3.043 = 1.70×。
共享边覆盖 = Air 高 / 本机高：183/360 = 50.8%；206/360 = 57.2%。
指针按 mm/s 归一化，所以物理速度 1:1；逻辑像素倍率只用于注入换算。禁止整屏 0..1 相对映射。

注意：`Xft.dpi=192` 只是 UI 提示，GDK 实际 scale factor 可能不同；macOS 1470×956 是“看起来像”模式，backing 为 2940×1912 后下采样到 2560×1664，不能假设 scale=2.0。两端关闭鼠标加速。
